# Security Policy

## Supported versions

Security fixes land on `main`. This project is source-first (users build from the repo); there is no separate notarized binary release channel.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Email **thedev@devvor.ai** with:

- A short description of the issue
- Steps to reproduce or a proof of concept
- Impact (e.g. unexpected network use, credential leak, privilege escalation)

We will acknowledge receipt as soon as possible and coordinate a fix before any public disclosure.

## Scope notes

This app requests **Microphone** and **Accessibility** so it can record audio and paste text into other apps. Reports that clarify how those permissions are used, or that reduce their blast radius, are especially welcome.

Do not include transcription text or personal audio in reports unless required to demonstrate the issue; scrub samples when possible.
